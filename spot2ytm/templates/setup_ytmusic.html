YouTube Music has no public API for playlists, so spot2ytm talks to it the way your browser does, using the headers of a logged-in session. They stay in your local data/ folder.

  1. Open music.youtube.com in Chrome, Edge or Firefox and make sure you are logged in.
  2. Open the developer tools (F12 or Ctrl+Shift+I) and go to the Network tab.
  3. Type browse in the filter box, then click Library (or anything) on the page so a request shows up.
  4. Find a POST request to browse?… with status 200 and click it.
  5. Copy its request headers:
    • Chrome / Edge: in Headers → Request Headers, select everything from accept: */* down to the end and copy.
    • Firefox: right-click the request → Copy Value → Copy Request Headers.
  6. Paste them below. They must contain cookie and x-goog-authuser.
Is this safe?

The headers give access to your Google account session, just like your browser cookies. spot2ytm keeps them in data/ytmusic_auth.json (readable only by your user) and only sends them to music.youtube.com. Never share that file. Logging out of YouTube Music in the browser invalidates them; they otherwise last a long time.
