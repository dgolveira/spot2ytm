Spotify only lets apps read your playlists through a developer app that you own. It is free and only you will use it. You do this once.

  1. Open the Spotify Developer Dashboard and log in. (The app owner needs Spotify Premium.)
  2. Click Create app. Any name and description will do.
  3. In Redirect URIs, add exactly:
    {{ redirect_uri }}
  4. Under Which API/SDKs are you planning to use? tick Web API, accept the terms and save.
  5. Open the app's Settings, copy the Client ID and paste it below. No client secret is needed.

spot2ytm only asks for read access to your playlists and Liked Songs. It never changes anything on Spotify.
