Works with Spotify Free: spot2ytm reads Spotify's public pages, so no developer app is needed.

  1. Public playlist or album: paste its link (Share → Copy link). Spotify's public page only lists the first {{ EMBED_TRACK_LIMIT }} songs.

Importing the same playlist again, or a song list with the same name, only adds the new songs to the same YouTube Music playlist.
